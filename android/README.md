# Auto Skip 安卓版

Android 0.1.2 开发预览版，2026-10-05。原生 Java + Android 系统界面，支持 Android 8.0（API 26）及以上的抖音安卓客户端（`com.ss.android.ugc.aweme`）。APK 无第三方运行时、无联网权限，安装后无需电脑、数据线、Root 或 API Key。

桌面与 Chrome 的使用说明见[项目首页](../README.md)。两端数据库独立；安卓 0.1.2 新视频拉黑／学习规则默认「或」，桌面仍为「仅视频」。

## 安装与使用

1. 安装构建生成的 `android/dist/AutoSkip-Android-0.1.2.apk`（相对于仓库根目录）。使用 ADB 时执行 `adb install -r android/dist/AutoSkip-Android-0.1.2.apk`。APK 未提交到 Git，源码构建步骤见下文。
2. 打开 Auto Skip，点击「开启无障碍服务」，阅读说明后在手机系统设置中开启「Auto Skip 视频过滤」。服务启动时总开关始终暂停。
3. 在首页选择「监听」「自动过滤」「自动收藏」；默认监听与自动收藏开启，自动过滤关闭。点击「开始」并打开抖音推荐视频页。
4. 抖音中显示圆形浮窗：点圆钮开始，再点暂停；点圆钮下沿小箭头展开面板，点面板顶部收起。拖动圆钮或展开面板的顶部调整位置，拖动不切换运行状态。默认折叠主圆钮直径 24 dp，下沿展开入口 14×12 dp；在当前 Mate 40 Pro 上分别为 72 像素和 42×36 像素。在「设置 → 浮窗透明度」下方的「折叠浮窗大小」滑动条中可调为默认的 75%～200%，圆钮、图标和下沿入口一起缩放，设置自动保存；展开面板大小保持固定。折叠时不显示状态、作者或标题文字，展开后可查看并拉黑作者／视频、重读、撤销或进入管理页。离开抖音或锁屏时隐藏浮窗并停止观察和动作。
5. 黑名单、收藏、统计和设置使用底部导航；规则与收藏支持搜索，列表分批显示，按钮适合触屏。
6. 首页右上角电源图标用于「退出 Auto Skip」：停止监听、过滤、收藏和定时观察，移除浮窗并关闭应用页面。退出状态会保存，系统重新连接服务时不会自行恢复浮窗。再次打开 Auto Skip 后恢复为暂停状态，点击开始即可使用；无障碍授权和本机数据保留。

华为 Mate 40 Pro 若在后台停止服务，在手机「设置 → 应用 → 应用启动管理」中找到 Auto Skip，手动允许后台运行。不同系统版本的菜单可能不同。Android 13 及以上若禁止侧载应用开启无障碍，需由用户在应用信息页允许该应用的受限设置，再返回无障碍设置开启服务。

## 功能

- 作者、关键词、链接的「或／与」规则；添加、编辑、启用／停用、删除。
- 从浮窗拉黑作者或当前视频，并上滑一次；缺少作者时拒绝拉黑。从视频拉黑及快速划走学习的新规则默认选择「任一符合（或）」，保存作者、可读标题关键词和可取得的真实视频链接；没有真实链接时链接字段留空。作者、关键词、链接任一匹配即可过滤，因此也会命中同作者的其他视频。
- 默认快速阈值为 5 秒，严格低于阈值才学习；等于阈值不学习。快速手动上滑学习仅在确认视频变化、存在近期视频容器滚动事件、且有完整的上一条观看区间时执行。工具自己的上滑不学习。已有规则保留原选择；旧「仅视频」规则可在编辑中改成「任一符合（或）」或「全部符合（与）」。
- 观看统计包含全部、有效、跳过及本机关键词分类。有效观看严格超过快速阈值；只记录两次确认切换之间的完整区间。启动时已在播放的第一条、离开视频页前没有结束的最后一条不保存。暂停工具、锁屏、离开抖音会丢弃未完成区间。
- 观看记录 JSON 导出、合并导入和确认后重置。导入先校验全部数据，在事务中写入；重复导入去重，真实重复的观看记录按次数保留。可导入桌面导出的 `autoskip-watches` v1 记录；安卓新生成记录使用 `source=android`，含此来源的备份当前不能反向导入桌面。
- 默认观看严格超过 5 分钟立即加入本机收藏，设置中可调整阈值。收藏支持搜索、编辑、勾选批量复制链接／删除、确认后清空；已知不同视频 ID 分别保存，手工编辑后不重复收藏。
- 可选「按历史时长跳过」，默认关闭，需要同时开启自动过滤。同视频有效历史均值优先；否则使用匹配类别中样本最多的均值。没有可靠视频身份或有效历史时继续观看。
- 浮窗位置与透明度、功能开关、规则、观看记录和收藏在手机上持久保存。总运行状态不持久化，服务重启不会自行开始上滑。

## 手机适配与实际限制

安卓通过[无障碍服务](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)读取可见作者／标题，使用系统 `dispatchGesture` 上滑；浮窗使用无障碍覆盖窗口。不会操作抖音账号的拉黑、点赞、不感兴趣或收藏按钮。

当前实现需要抖音暴露可见作者和视频操作栏；推荐流内的直播卡也通过视频容器与进入直播间标记识别，实际直播间不自动处理。评论、搜索、分享、主页和输入中的页面会等待，不执行自动过滤。视频切换时允许短暂空白，保留待确认动作；3 秒仍未确认切换会暂停，防止连续上滑。未知界面不猜测作者。没有配置屏幕截图 OCR，因此完全隐藏无障碍文字的抖音版本需要增加适配。

通常抖音视频页不提供真实分享链接，程序不会自动打开分享面板或读取无关剪贴板。取得标准视频链接时按 ID 匹配；没有链接时用作者 + 可读标题识别视频，收藏显示「未取得链接」，可手工补填。同名作者、同作者同标题视频无法完全区分；抖音将文案折叠为“展开”时仅使用可见内容，不主动展开。没有足够标题文字时仅能使用作者／关键词过滤，无法可靠学习或收藏该视频。

播放暂停信号只有在界面提供「播放／继续播放」时可识别；其他不可见的暂停或缓冲仍可能计入自动收藏。没有可靠播放结束信号，因此普通视频由用户上滑，或使用可选历史时长跳过。

安卓数据库与桌面数据库独立保存，不自动同步。桌面快捷键、窗口绑定及 Windows OCR 排除区域被手机浮窗、触屏按钮和抖音包名绑定替代。

## 数据与备份

黑名单、收藏和观看记录保存在应用私有 SQLite 数据库中，开关、阈值、浮窗位置／透明度／大小及退出状态保存在私有设置中。APK 配置关闭系统自动备份；清除应用数据或卸载会移除这些本机数据。使用同一签名的 APK 更新安装可保留原数据。

「统计 → 导出记录」生成 `autoskip-watches` v1 JSON，仅备份观看记录，不包含黑名单、收藏或设置。导入支持合并与重复次数去重，重置统计不影响规则和收藏。当前没有黑名单、收藏与设置的完整导出入口；需要保留这些数据时请保持原安装与应用数据。

## 构建与检查

Windows PowerShell，JDK 17+。构建脚本通过官方 SDK 工具直接编译，没有 Gradle 或应用依赖。

```powershell
.\android\build.ps1 -Check -DeviceTests
# 可指定 JDK；SDK 缓存在项目 .local/android-toolchain，首次构建需网络。
.\android\build.ps1 -JavaHome 'C:\path\to\jdk' -Check
# 连接设备后构建、安装并打开：
.\android\build.ps1 -Check -Install -Serial '设备序列号'
```

Android SDK Platform 35 和 Build Tools 35.0.0 来自 Google 官方下载，并按官方清单的 SHA-1 校验。遵循 [Android SDK 条款](https://developer.android.com/studio/terms)。这是开发预览包，以本机生成的开发证书签名；需要更新安装时保留 `.local/android-toolchain/debug.keystore`。

从仓库根目录运行以上命令。主安装包输出到 `android/dist/AutoSkip-Android-0.1.2.apk`，中间产物位于 `android/.local/build`；这些目录及 SDK 缓存、开发证书均被 Git 忽略。`-Install` 另需已在 PATH 中的 `adb` 与已授权的设备连接；正常手机使用不依赖 ADB。

`-Check` 执行可独立运行的 Java 核心检查；`-DeviceTests` 另生成测试 APK，其中 SQLite 使用内存数据库，不操作抖音，也不修改用户黑名单／收藏。

```powershell
adb install -r android/dist/AutoSkip-Android-checks.apk
adb shell am instrument -w com.autoskip.android.tests/com.autoskip.android.DeviceCheck
```

实机检查情况见 [VALIDATION.md](VALIDATION.md)。
